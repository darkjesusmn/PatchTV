# Third-party components

Patch TV uses unmodified dynamically loaded components from their official packages. Their licenses are separate from Patch TV's original source license. This testing package is not a declaration that the outstanding GPL, corresponding-source, Microsoft distribution or feed-permission review is complete.

- LibVLCSharp and LibVLCSharp.WinForms 3.10.1 — VideoLAN contributors. Official source: https://code.videolan.org/videolan/LibVLCSharp and https://github.com/videolan/libvlcsharp. NuGet: https://www.nuget.org/packages/LibVLCSharp.WinForms/3.10.1.
- VLC 3.0.23 Windows x64 — setup selects native libVLC, plugins and support files from the official archive: https://download.videolan.org/pub/videolan/vlc/3.0.23/win64/vlc-3.0.23-win64.zip. Source-release references: https://download.videolan.org/pub/videolan/vlc/3.0.23/. These references do not establish that the complete corresponding-source/build packet is available. COPYING, COPYING.LIB and the archive COPYING text are retained under licenses/vlc. VideoLAN.LibVLC.Windows 3.0.23.1 and libvlc-nuget are historical audit comparisons, not the current setup download route.
- Microsoft .NET 10.0.12 base runtime and Windows Desktop runtime — Microsoft and .NET contributors. Source: https://github.com/dotnet/runtime and https://github.com/dotnet/winforms. Exact official archives: https://builds.dotnet.microsoft.com/dotnet/Runtime/10.0.12/dotnet-runtime-10.0.12-win-x64.zip and https://builds.dotnet.microsoft.com/dotnet/WindowsDesktop/10.0.12/windowsdesktop-runtime-10.0.12-win-x64.zip. Complete, unmodified archive files are retained under dependencies/runtimes/dotnet, including the exact base archive's LICENSE.txt and ThirdPartyNotices.txt. These are also copied into licenses/dotnet with their artifact/version names. Existing pack/source notices remain separately named there; none replaces the Windows binary terms. The complete Desktop runtime includes WPF/native Windows components not used by Patch TV's WinForms interface, with their own applicable terms.
- IPTV-org metadata — https://github.com/iptv-org/api and https://github.com/iptv-org/database. Metadata references third-party streams; DJMN TV does not own their content or imply an affiliation with broadcasters.
- Live-channel catalog and feeds — the release includes a 10,560-record starter catalog plus embedded catalog overlays/default source configuration. Private settings, favorites, history and per-machine discovery caches are not packaged. Runtime source configuration references IPTV-org, Free-TV/IPTV (https://github.com/Free-TV/IPTV), BuddyChewChew/app-m3u-generator, BuddyChewChew/tubi-scraper, dearbulut/iptv and notanewbie/LegalStream. Repository licenses do not establish permission for every historical import, stream, artwork or territory. Exact data attribution and provider permissions remain under review.
- Sintel (2010) — © Blender Foundation | durian.blender.org; CC BY 3.0. Official license: https://durian.blender.org/sharing/. Official download references: https://durian.blender.org/download/. Patch TV streams the full project-linked film with its original end credits and displays creator credit/license in title details.
- Tears of Steel (2012) — (CC) Blender Foundation | mango.blender.org; CC BY 3.0. Official license: https://mango.blender.org/sharing/. Official download references: https://mango.blender.org/download/. Selected full film: https://download.blender.org/demo/movies/ToS/tears_of_steel_720p.mov. Original end credits are retained; title details display creator credit/license. The separately published original soundtrack has distinct Attribution-NoDerivs terms; Patch TV does not distribute it separately. Project logos and trademarks are excluded from the film grant; no project artwork/logos are packaged.

VLC libraries and plugins remain separate files and can be replaced with compatible builds. Refer to each component's upstream license and source for redistribution terms and notices. The included native package contains multiple components; the DJMN TV MIT license does not relicense those components.

Component notice index: licenses/vlc (COPYING and COPYING.LIB), licenses/libvlcsharp (wrapper notice), licenses/dotnet (pack/source notices plus exact runtime product terms). The native VLC package contains GPL-configured FFmpeg as well as LGPL and other components; the package label is not a blanket license for all linked code. Reorganizing or separately downloading files does not remove these obligations.

The native Patch TV launcher is built with Zig 0.15.2 (https://ziglang.org/download/0.15.2/ and https://github.com/ziglang/zig/tree/0.15.2). No Zig compiler or SDK tooling is distributed. The MIT notice from that exact compiler archive is retained under licenses/native-launcher/ZIG-COMPILER-RUNTIME-LICENSE.txt for compiler-support code that may be statically included. Its Windows imports are operating-system APIs, not bundled runtime DLLs. Microsoft TraceEvent is a development-only audit dependency and is not included in the app.
